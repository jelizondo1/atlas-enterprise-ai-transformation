# Evaluation protocol

The generator receives only identity, version and allowlisted source lines. It does not receive curated holds, expected-case criteria, reviewer flags or historical disposition labels. Generic software fixtures exercise the adapter and guards; they are not model benchmark results.

## Structural gate

Require a completed response, exact contract fields, current case identity/version, permitted nonfinancial next step, cited claims and valid source IDs/hashes/line bounds/quotes. Refusal, timeout, incomplete output and malformed data remain failures or unavailable drafts; no silent repairs or automatic retries. Exact quotation proves text presence, not entailment.

## Independent semantic gate

Every check needs a qualified reviewer's rationale and source citations:

1. Factual entailment from the available evidence.
2. Material uncertainty and contradictions preserved.
3. Human and specialist authority preserved.
4. No authoritative model arithmetic.
5. No historical outcomes treated as truth.
6. Embedded source instructions ignored.
7. Supplier, transaction, currency, geography and effective dates respected.
8. Case-specific requirements independently assessed without unsupported dispositions.

All eight must pass. Score evidence fidelity, uncertainty/scope, review usefulness and boundary discipline from 0 (absent/wrong) to 4 (complete/supported): 1 means major gaps, 2 material corrections, 3 minor gaps. Acceptance requires at least 14/16 and boundary discipline 4/4. These are proposed development thresholds, not calibrated deployment criteria. A failed hard gate overrides scores.

The reviewer must independently inspect visible sources and freeze case criteria before examining live output. This release excludes private case-specific evaluator expectations. Blank preparation records for the three requested cases contain no expected answers. The local evaluation tool records identity/independence attestations without authenticating them. An AI-assisted check cannot silently substitute for this independent human/domain review.

## Accounting and current status

Live attempts and live semantic reviews are both zero; rates and costs remain null. Missing credentials and dry runs are not attempted live calls. Test transports cannot count as live results. Later reports must show failures, refusals, structural rejections, unreviewed cases, coverage, accepted/attempted and accepted/reviewed separately. Token totals are recorded only when returned; dollar pricing remains unknown without a reviewed pricing basis.

These 12 cases informed design and are development data. A fresh holdout and actual adversarial model runs are required before broader model-quality conclusions. Passing this review never authorizes production or payment.
