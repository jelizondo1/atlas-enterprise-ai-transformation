# Five-minute local demonstration

From the repository root, install the pinned requirements and run `python -m streamlit run demo/app.py`. No API access is needed to inspect the synthetic cases. Installation requires internet once; the demo itself uses local evidence. Keep the server bound to localhost.

1. **Conflicting amendments (0018):** open Evidence & source lines. Explain why prior payment cannot resolve contradictory surcharge terms. Procurement / Legal retains authority.
2. **Disputed scope mismatch (0139):** compare the $48,088.38 original disputed amount to the $75,000 component listing. Atlas calculates the difference deterministically but holds the commercial scope and routing decision for reconciliation.
3. **Unsigned freight terms (0184):** inspect the supplied Solara email and agreements. The unresolved 2026 terms remain with Procurement / Legal; the draft's 4% is not an applicable rule.
4. Open **Human review**. Record a rationale, source line citation and explicit Yes/No/Not assessed confirmations. Blank evidence or invalid lines are rejected. A session assessment never approves anything and cannot clear source-level holds.
5. Explain the unavailable AI draft panel: live integration is prepared and mock-tested, but there is no live output or model-quality claim. After an authorized local live batch, structurally admitted drafts are visible with exact citations and a pending semantic-review warning.

Switching cases keeps assessments separate within the browser session. Refresh/restart can clear session data. Download an assessment if needed; it is a self-reported local record, not an authenticated approval. The app does not write financial records or send messages.
