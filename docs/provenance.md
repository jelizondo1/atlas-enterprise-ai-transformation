# Source lineage and public export

The internal development packages remain authoritative and unchanged. This public export selects capability artifacts, removes nested copies and rebases runtime paths to a shared source pack. Original development-stage names are retained only in the machine-readable provenance record where needed to identify the upstream file.

All eighteen policy/agreement/case/CSV source files retain original bytes, with the historical CSV renamed for public organization. The source README is a sanitized overview that preserves the original dataset-baseline and fictional-data sections. It contains no hidden evaluation material. Source citations in the opportunity map use repository-root paths, public hashes and original JSON pointers. Narrative report links are relative to their containing file.

Runtime modules retain the existing deterministic logic and authority boundaries. Import paths, folder names and the draft bridge filename were adapted for the public layout. New work includes the Streamlit demo, bounded three-case live command, package checks and portfolio documentation. Human review in the demo records only a local session assessment.

Private case-specific evaluator expectations, original hidden ground truth, historical evaluator scores and development run output are excluded. Explicit public controls and software test fixtures remain because they explain and verify behavior. They are transparent design logic, not a blind benchmark. Do not use this public development set as an unseen holdout.

[Machine-readable file lineage](provenance.json) records both original and exported hashes. New public-only files are enumerated by the release file list.
