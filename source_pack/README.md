# Meridian synthetic source pack

Policies, supplier agreements, historical intake rows and 12 case evidence packets. All records are fictional portfolio material. Historical dispositions are observations, not correctness labels.

## Dataset baseline
- 250 historical dispute cases
- Average handling time: 24.0 minutes
- Average final resolution time: 6.8 business days
- SLA attainment: 62.0%
- Reopen rate: 14.0%
- Multiple suppliers, systems, evidence types, and intentionally imperfect intake classifications

## Important
All companies, people, invoices, transactions, and documents in this pack are fictional and created solely for the Atlas portfolio project.
